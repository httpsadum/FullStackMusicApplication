# Full-Stack Music Library Application

A full-stack Music Library application built using **HTML, CSS, JavaScript, Node.js, Express.js, and SQLite**.

The application allows users to manage artists, albums, and songs through a web-based interface. The frontend communicates with a RESTful backend API, which stores and retrieves persistent data from an SQLite database.

## Features

- Artist management
  - View all artists
  - View an individual artist
  - Create artists
  - Update artists
  - Delete artists
- Album management
  - View all albums
  - View an individual album
  - Create albums
  - Update albums
  - Delete albums
- Song management
  - View all songs
  - View an individual song
  - Create songs
  - Update songs
  - Delete songs
- Persistent SQLite database storage
- Foreign key relationships between artists, albums, and songs
- Cascading deletes
- RESTful API
- Frontend/backend integration using `fetch()`
- CORS support
